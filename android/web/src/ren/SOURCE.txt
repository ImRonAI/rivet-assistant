These files are never edited here (SHA256SUMS holds their hashes; `npm run check:ren` verifies them). The file list is
the import closure of src/pages/SearchResultsPage.tsx and of the components ren desktop's agent panel
(src/components/agent-panel/AgentPanel.tsx) draws a conversation with: ai-elements/conversation, message, response,
chain-of-thought, tool and shimmer:

  esbuild src/pages/SearchResultsPage.tsx --bundle --packages=external --metafile=meta.json --outfile=/dev/null

plus the files those import for their types only (found by `tsc -b`), which are checked but never bundled.

The phone's search page (src/search/) mounts SearchResultsPage as it is and supplies what Electron supplies on the
desktop. Its agent panel's chat (src/panel/) draws the conversation with those components the way AgentPanel.tsx does.
